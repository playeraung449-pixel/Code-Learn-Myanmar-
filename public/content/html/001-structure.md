# Title: HTML Structural Tags နှင့် စာမျက်နှာတည်ဆောက်ခြင်း

## Introduction
မင်္ဂလာပါ ခင်ဗျာ။ Web Development လောကသို့ လှိုက်လှဲစွာ ကြိုဆိုပါတယ်။ သင်မြင်တွေ့နေရတဲ့ မည်သည့်ဝက်ဘ်ဆိုက်မဆို နောက်ကွယ်မှာ HTML နဲ့သာ အခြေခံတည်ဆောက်ထားတာ ဖြစ်လို့ ဝက်ဘ်ပညာရှင်ဖြစ်ဖို့ အခြေခံအကျဆုံး တံခါးပေါက်တစ်ခု ဖြစ်ပါတယ်။

## Learning Objectives
ဤသင်ခန်းစာ ပြီးမြောက်ပါက အောက်ပါတို့ကို တတ်မြောက်နိုင်မည် ဖြစ်ပါသည် -
1. HTML (HyperText Markup Language) ၏ သဘောတရားကို ကောင်းစွာ နားလည်ခြင်း။
2. HTML structure ရဲ့ အခြေခံအကျဆုံး tags များကို သိရှိခြင်း။
3. ကိုယ်ပိုင် homepage တစ်ခုကို အစမှစတင်၍ ရေးသားနိုင်ခြင်း။
4. Hyperlinks နှင့် ပုံရိပ်များကို စနစ်တကျ ချိတ်ဆက်တတ်ခြင်း။

## Theory
HTML (HyperText Markup Language) ဆိုသည်မှာ ဝက်ဘ်ဆိုက်တစ်ခု၏ "အရိုးစု" သို့မဟုတ် တည်ဆောက်ပုံကို ဖန်တီးပေးသည့် Markup Language ဖြစ်သည်။ စာသားများ၊ ပုံများ၊ ဗီဒီယိုများကို ဝက်ဘ်စာမျက်နှာပေါ်တွင် မည်သည့်နေရာ၌ မည်သို့ထားမည်ကို tags များကို သုံး၍ သတ်မှတ်ပေးသည်။

## Syntax
HTML တွင် tag များကို `<tagname>` ပုံစံဖြင့် ဖွင့်ပြီး၊ `</tagname>` ပုံစံဖြင့် စနစ်တကျ ပြန်ပိတ်ပေးရသည် -
```html
<!DOCTYPE html>
<html>
<head>
    <title>ငါ့ဝက်ဘ်ဆိုက်</title>
</head>
<body>
    <h1>မင်္ဂလာပါကမ္ဘာလောက</h1>
</body>
</html>
```

## Code Examples
```html
<!-- Header & Text Tag များ -->
<h1>အကြီးဆုံး ခေါင်းစဉ် (Heading 1)</h1>
<h2>ဒုတိယအကြီး ခေါင်းစဉ် (Heading 2)</h2>
<p>ဝက်ဘ်ဆိုက်စာပိုဒ်များ ရေးသားရန် (Paragraph)</p>

<!-- Link & Image Tag များ -->
<a href="https://google.com">Google သို့သွားရန် လင့်ခ်</a>
<img src="logo.png" alt="ဝက်ဘ်ဆိုက်လိုဂို" />
```

## Explanation
- `<!DOCTYPE html>` သည် ဤဖိုင်သည် HTML5 ဗားရှင်းဖြစ်ကြောင်း browser သို့ ပြောပြခြင်းဖြစ်သည်။
- `<html>` သည် တစ်ခုလုံး၏ အခြေခံ root tag ဖြစ်သည်။
- `<head>` တွင် page configuration များနှင့် ခေါင်းစဉ် (`<title>`) ကို သိမ်းဆည်းသည်။
- `<body>` တွင် ဝက်ဘ်ဆိုက်ပေါ်တွင် တကယ်ပြသမည့်အရာအားလုံး ပါဝင်သည်။

## Output
Browser ပေါ်တွင် မြင်တွေ့ရမည့်ပုံစံမှာ -
- **အကြီးဆုံး ခေါင်းစဉ် (Heading 1)** ကဲ့သို့သော စာသားကြီးများ
- Click နှိပ်၍ရသည့် **Google သို့သွားရန် လင့်ခ်** များ ဖြစ်သည်။

## Common Mistakes
1. **ပိတ် tag `/` မေ့လျော့ခြင်း**: `<h1>မင်္ဂလာပါဦးလေး` (ပြန်မပိတ်ပါက စာလုံးဒီဇိုင်းများ ပျက်စီးနိုင်သည်)
2. **Nesting မှားယွင်းခြင်း**: `<p><b>စာသား</p></b>` (မှန်ကန်သောပုံစံမှာ `<p><b>စာသား</b></p>` ဖြစ်သည်)

## Best Practices
- Tag အားလုံးကို အမြဲတမ်း စာလုံးအသေးဖြင့်သာ ရေးပါ။ ဥပမာ - `<H1>` အစား `<h1>` ဟု ရေးပါ။
- ကုဒ်များဖတ်ရလွယ်ကူစေရန် space များနှင့် indentation များကို စနစ်တကျ အသုံးပြုပါ။

## Tips
💡 HTML code များကို Visual Studio Code ကဲ့သို့သော Text Editor တွင် ရေးသားပြီး `.html` extention ဖြင့် သိမ်းဆည်းကာ browser ဖြင့် တိုက်ရိုက်ဖွင့်ကြည့်နိုင်ပါသည်။

## Mini Project
**ခေါင်းစဉ်**: My First Homepage (ပထမဆုံးကိုယ်ပိုင်ပင်မစာမျက်နှာ)
**ဖော်ပြချက်**: ခေါင်းစဉ်တစ်ခု၊ စာပိုဒ်တစ်ခု နှင့် Google သို့သွားမည့် link တစ်ခုပါဝင်သော ကိုယ်ပိုင် အခြေခံ Profile ဝက်ဘ်ဆိုက် စာမျက်နှာတစ်ခု ဖန်တီးပါ။
**လုပ်ဆောင်ရန်အဆင့်များ**:
1. `<h1>` tag ဖြင့် သင့်နာမည်ရေးပါ။
2. `<p>` tag ဖြင့် သင့်အကြောင်းအကျဉ်းရေးပါ။
3. `<a>` tag ဖြင့် link ချိတ်ပါ။
**အရင်းအမြစ်များ**: HTML text elements
**ကုဒ်အဖြေ**:
```html
<!DOCTYPE html>
<html>
<head>
    <title>My Profile</title>
</head>
<body>
    <h1>Aung Myo</h1>
    <p>ကျွန်တော်ကတော့ နည်းပညာလေ့လာနေသူတစ်ဦး ဖြစ်ပါတယ်။</p>
    <a href="https://facebook.com">ကျွန်တော့်ကို Facebook မှာဆက်သွယ်ပါ</a>
</body>
</html>
```
