# Title: Variables (ကိန်းရှင်များ) အကြောင်းလေ့လာခြင်း

## Introduction
မင်္ဂလာပါခင်ဗျာ။ ပရိုဂရမ်မင်းလောကထဲကို စတင်ဝင်ရောက်လာတဲ့ ကျောင်းသားကျောင်းသူများကို နွေးထွေးစွာ ကြိုဆိုပါတယ်။ ကွန်ပြူတာပရိုဂရမ်တစ်ခု ရေးသားတဲ့အခါမှာ ဒေတာတွေကို သိမ်းဆည်းဖို့နဲ့ ပြန်လည်အသုံးပြုဖို့က အခြေခံအကျဆုံး အစိတ်အပိုင်း ဖြစ်ပါတယ်။ အဲဒီလို ဒေတာတွေကို သိမ်းဆည်းဖို့အတွက် Variables (ကိန်းရှင်များ) ကို အသုံးပြုရပါတယ်။

## Learning Objectives
ဤသင်ခန်းစာ ပြီးမြောက်ပါက အောက်ပါတို့ကို တတ်မြောက်နိုင်မည် ဖြစ်ပါသည် -
1. Variables (ကိန်းရှင်) ၏ သဘောတရားကို ကောင်းစွာ နားလည်သဘောပေါက်ခြင်း။
2. Python ဘာသာစကားတွင် Variables များကို စနစ်တကျ ကြေညာအသုံးပြုတတ်ခြင်း။
3. Data Types အမျိုးမျိုး (ကိန်းပြည့်၊ ဒဿမ၊ စာသား၊ Boolean) တို့ကို ခွဲခြားသိမြင်ခြင်း။
4. ကိန်းရှင်များ အသုံးပြုရာတွင် မဖြစ်မနေ လိုက်နာရမည့် နည်းစနစ်ကောင်းများကို တတ်မြောက်ခြင်း။

## Theory
Variables ဆိုသည်မှာ ကွန်ပျူတာ၏ RAM memory ထဲတွင် ဒေတာများကို ခေတ္တသိမ်းဆည်းထားရန် အသုံးပြုသည့် လိပ်စာကတ်ပြား သို့မဟုတ် "အမည်တပ်ထားသော သေတ္တာလေးများ" ဖြစ်သည်။ ဥပမာ - အဝတ်အစားထည့်သည့် သေတ္တာတွင် "အင်္ကျီ" ဟု စာကပ်ထားပြီး အဝတ်အစားများ သိမ်းဆည်းသကဲ့သို့၊ Variables ထဲတွင် အသုံးပြုသူ၏ အချက်အလက်များ (ဥပမာ - အသက်၊ နာမည်၊ ရမှတ်) ကို သင့်လျော်သော အမည်တစ်ခုပေး၍ သိမ်းဆည်းထားနိုင်သည်။

## Syntax
Python တွင် variable ကြေညာရန် အခြားသော ဘာသာစကားများကဲ့သို့ Type သီးသန့် ပြောပြရန်မလိုဘဲ တိုက်ရိုက် Assign ပြုလုပ်နိုင်သည် -
```python
variable_name = value
```

## Code Examples
```python
# ကိန်းပြည့် (Integer) သတ်မှတ်ခြင်း
points = 1500

# စာသား (String) သတ်မှတ်ခြင်း
username = "Mg Mg"

# ဒဿမကိန်း (Float) သတ်မှတ်ခြင်း
price = 450.50

# Boolean (True / False) သတ်မှတ်ခြင်း
is_student = True
```

## Explanation
- `points = 1500` တွင် `points` သည် variable ၏ နာမည်ဖြစ်ပြီး `1500` သည် ၎င်းသေတ္တာထဲသို့ ထည့်လိုက်သည့် တန်ဖိုး (Value) ဖြစ်သည်။
- `=` (Assignment Operator) သည် ညာဘက်မှ တန်ဖိုးကို ဘယ်ဘက်မှ ကိန်းရှင်ထဲသို့ ထည့်သွင်းပေးရန် သုံးသည်။
- Python သည် Dynamic Typing ကို အသုံးပြုသောကြောင့် တန်ဖိုးအမျိုးအစားအလိုက် Type ကို သူ့အလိုလို သတ်မှတ်ပေးသည်။

## Output
အထက်ပါ variable များကို `print()` သုံး၍ ထုတ်ပြပါက ရရှိမည့် output များမှာ -
```bash
points: 1500
username: Mg Mg
price: 450.5
is_student: True
```

## Common Mistakes
1. **နံပါတ်ဖြင့် စတင်ခြင်း**: `1name = "Mya Mya"` (ဂဏန်းဖြင့် စတင်ခွင့်မရှိပါ)
2. **Space ခြားခြင်း**: `my name = "Kyaw Kyaw"` (ကွက်လပ်ခြားခွင့်မရှိပါ)
3. **အထူးသင်္ကေတများ အသုံးပြုခြင်း**: `user-name = "Aung Aung"` (Hyphen သုံးခွင့်မရှိပါ)

## Best Practices
- Variable နာမည်များကို အဓိပ္ပာယ်ရှိရှိ ပေးပါ။ ဥပမာ - `x = 20` ထက် `user_age = 20` က ပိုကောင်းသည်။
- Python တွင် variable များကို သေးငယ်သောစာလုံး (lowercase) နှင့် မြေအောက်မျဉ်း (snake_case) ကို သုံးပါ။ ဥပမာ - `student_score`

## Tips
💡 Variable များကို အမြဲတမ်း စာလုံးသေးဖြင့် စတင်ရေးသားရန် အကြံပြုလိုပါသည်။ ၎င်းသည် သင်၏ ကုဒ်များကို အခြားသူများ ဖတ်ရှုရာတွင် သပ်ရပ်လွယ်ကူစေပါလိမ့်မည်။
