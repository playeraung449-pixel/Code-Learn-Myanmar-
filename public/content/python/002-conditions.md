# Title: If-Else Conditions (အခြေအနေခွဲခြားခြင်း) အကြောင်းလေ့လာခြင်း

## Introduction
မင်္ဂလာပါ ခင်ဗျာ။ ပရိုဂရမ်တစ်ခုကို လူသားတစ်ဦးလို ဉာဏ်ရည်ရှိရှိ ဆုံးဖြတ်ချက်ချခိုင်းတတ်စေဖို့ If-Else Conditions က အလွန်အရေးကြီးပါတယ်။ အပြင်မှာ မိုးရွာရင် ထီးယူသွားမယ်၊ မရွာရင် မယူသွားဘူး ဆိုတဲ့ ဆုံးဖြတ်ချက်တွေလိုပဲ ပရိုဂရမ်ထဲမှာလည်း အခြေအနေတွေအလိုက် အလုပ်လုပ်ပုံကို ခွဲခြားနိုင်ပါတယ်။

## Learning Objectives
ဤသင်ခန်းစာ ပြီးမြောက်ပါက အောက်ပါတို့ကို တတ်မြောက်နိုင်မည် ဖြစ်ပါသည် -
1. If-Else logic ၏ သဘောတရားနှင့် ဆုံးဖြတ်ချက်ချပုံကို နားလည်ခြင်း။
2. Python တွင် `if`, `elif`, `else` တို့ကို သုံးစွဲတတ်ခြင်း။
3. Indentation (စာကြောင်းအကွာအဝေး) ၏ အရေးကြီးပုံကို သိရှိလိုက်နာခြင်း။
4. နှိုင်းယှဉ်သင်္ကေတများ (Comparison Operators) ကို ကျွမ်းကျင်စွာ အသုံးပြုနိုင်ခြင်း။

## Theory
If-Else သည် ပရိုဂရမ်တစ်ခုကို အခြေအနေ (Condition) တစ်ခုခုအပေါ် မူတည်ပြီး ဆုံးဖြတ်ချက်ချခိုင်းခြင်း ဖြစ်သည်။ အခြေအနေ မှန်ကန်လျှင် (True ဖြစ်လျှင်) `if` block အောက်ရှိ ကုဒ်များကို လုပ်ဆောင်ပြီး၊ မှားယွင်းလျှင် (False ဖြစ်လျှင်) `else` block အောက်ရှိ ကုဒ်များကို လုပ်ဆောင်စေသည်။

## Syntax
Python တွင် `if-else` ရေးပုံရေးနည်းမှာ အောက်ပါအတိုင်း ဖြစ်ပါသည် -
```python
if condition:
    # condition မှန်ကန်လျှင် လုပ်ဆောင်မည့် ကုဒ်များ
else:
    # condition မှားယွင်းလျှင် လုပ်ဆောင်မည့် ကုဒ်များ
```

## Code Examples
```python
# ရမှတ်ပေါ်မူတည်၍ အောင်/ရှုံး ဆုံးဖြတ်ခြင်း
score = 65
if score >= 40:
    print("စာမေးပွဲ အောင်မြင်ပါသည်!")
else:
    print("ထပ်မံ ကြိုးစားပါဦး!")

# အသက်အရွယ်စစ်ဆေးခြင်း
age = 19
if age >= 18:
    print("မဲပေးပိုင်ခွင့်ရှိသည်")
else:
    print("မဲပေးရန် အသက်မပြည့်သေးပါ")
```

## Explanation
- `if score >= 40:` သည် ရမှတ် (score) ၄၀ နှင့်အထက် ရှိမရှိ စစ်ဆေးခြင်းဖြစ်သည်။
- Python တွင် block တစ်ခုကို သတ်မှတ်ရန် ကော်လံ `:` ကို အသုံးပြုရသည်။
- block အောက်ရှိ အလုပ်လုပ်မည့်ကုဒ်များကို ဘယ်ဘက်မှ စာလုံးအကွာအဝေး (Indentation) ၄ ချက် (Spaces) ခြားပြီး ရေးရသည်။

## Output
အထက်ပါ ကုဒ်များမှ ထွက်ရှိလာမည့် output မှာ -
```bash
စာမေးပွဲ အောင်မြင်ပါသည်!
မဲပေးပိုင်ခွင့်ရှိသည်
```

## Common Mistakes
1. **ကော်လံ `:` မေ့လျော့ခြင်း**: `if age >= 18` (အဆုံးတွင် `:` မပါဝင်ပါက syntax error တက်ပါမည်)
2. **Indentation (တန်းညှိခြင်း) အမှား**:
   ```python
   if age >= 18:
   print("Adult")  # block အတွင်းမဝင်သဖြင့် error တက်မည်
   ```

## Best Practices
- Indentation ကို တသမတ်တည်းဖြစ်အောင် spaces ၄ ကွက် (သို့မဟုတ် Tab ၁ ခု) ကိုသာ အသုံးပြုပါ။
- Nested Conditions (အခြေအနေများ ထပ်ဆင့်ဝင်ခြင်း) ကို တတ်နိုင်သမျှ ရှောင်ကြဉ်ပြီး ရိုးရှင်းအောင် ရေးပါ။

## Tips
💡 Python တွင် condition ၃ ခုနှင့်အထက် ရှိလာပါက `elif` (else if ၏ အတိုကောက်) ကို အသုံးပြု၍ အလယ်မှ အခြေအနေများကို စစ်ဆေးနိုင်ပါသည်။

- C: Semicolon ; သုံးခြင်းဖြင့်
